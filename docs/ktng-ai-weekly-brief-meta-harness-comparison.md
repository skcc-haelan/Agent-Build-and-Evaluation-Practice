# KT&G 주간 AI 브리핑 Agent 고도화 검증 보고서

- 실험일: 2026.10.01
- 기준 Agent: meta-harness baseline
- 최종 반영: v6 변경 사항을 `langchain-deepagents.py` 및 KT&G Skill에 반영
- 커밋: `98775ae` (Agent·Skill·평가자료), `3879283` (최종 가드레일)
- 푸시: `origin/main`
- 실행 조건: 질문별 격리 실행, recursion limit 60, timeout 900초

## 요약

기존 Agent는 6개 평가 질문 중 4개에서 `GraphRecursionError`로 답변을 만들지 못했다. 기본 질문은 보고 이력과 기간이 겹친다는 이유로 재확인을 요청하며 검색을 시작하지 않았다. 개선 후보 v5는 여섯 질문에 모두 보고서 파일을 생성했고, 마지막 v6에서는 0건일 때 가짜 뉴스 항목을 생성하지 않도록 보완해 q4·q5에서 재검증했다.

주요 개선은 Skill의 기본값을 따르는 실행, 검색 인증 실패 시 반복 호출 중단, 템플릿 고정, 수치·출처·루머 관련 규칙 충돌의 로그 처리다. 최종 변경은 시스템 프롬프트와 Skill에 반영되어 커밋·푸시됐다.

단, 모든 실행에서 Tavily가 `401 Unauthorized`를 반환해 보고서에 검증된 뉴스는 수록되지 않았다. 따라서 기간 안의 실제 기사 발굴, 원문 날짜, URL, 공식 1차 출처 인용 품질은 이 실험으로 검증하지 못했다.

## 개선 내용

1. **Skill 우선 실행**: Skill에 기간·절차 기본값이 있으면 확인 질문으로 멈추지 않고 적용한다. 기간이 이전 보고와 겹쳐도 중복 후보만 제외하고 계속 작성한다.
2. **검색 실패 시 제한된 처리**: 검색 전 단일 질의로 연결을 확인한다. 401/403이면 Tavily 재호출을 중단하고 설정된 대체 MCP만 한 번 확인한다. 대체 검색도 없으면 영향을 받은 소스와 후보 0건을 검증 로그에 남긴다.
3. **보고서 하드룰 준수**: 원문 밖 효과 수치를 만들지 않고, 출처 생략 및 공식 발표 전 루머 요청은 거부 사유를 검증 로그 B에 기록하면서 나머지 보고서를 작성한다.
4. **고정 템플릿 유지**: 도구 제한 설명이나 요청 거절 사유를 새 섹션으로 만들지 않는다. 후보가 0건이면 `[해당 없음]`을 뉴스 항목처럼 꾸미지 않고 해당 동향 절에 후보 없음만 적는다.

## 한계

- Tavily 검색이 모든 실험에서 HTTP 401을 반환했다. 본문 뉴스가 모두 0건이므로 실제 기사 정확도, 발행일 검증, 출처 URL 및 1차 출처 우선 인용 여부는 평가할 수 없다.
- v5에서 여섯 질문 모두 파일 산출에 성공했으나, 최종 v6와 동일한 조건으로 여섯 건 전체를 재실행한 것은 아니다. v6 변경은 q4·q5에서 확인했고, v6 q1 재실행은 5분 이상 대기해 완료되지 않았다.
- 모델 실행은 비결정적이며 질문별 반복 횟수는 제한적이다. 표의 시간과 호출 수는 품질 자체를 나타내지 않는다.

## 최종 판정

실험에서는 기존 Agent의 재귀 오류와 중복 확인 중단이 줄었고, 규칙 우회 요청 및 0건 출력의 처리도 개선됐다. 최종 변경은 `98775ae`, `3879283`에 커밋되어 `origin/main`에 푸시됐다. 다만 검색 API 인증 오류가 해결되기 전까지 정상 뉴스 수집과 출처 검증 품질에 대한 결론은 보류한다.
